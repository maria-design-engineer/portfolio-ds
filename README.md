# ds

Дизайн-система сайта-портфолио в коде: библиотека компонентов и витрина Storybook. Отдельный репозиторий рядом с `app/`.

## Команды

- `npm install` — зависимости по файлу замка `package-lock.json`
- `npm run storybook` — витрина, печатает локальный адрес
- `npm run build` — пакет в `dist/`: `ds.js` (ESM), `ds.css`, типы `.d.ts`
- `npm run build-storybook` — статическая витрина в `storybook-static/`
- `npm run check` — проверочный запуск окружения, см. ниже

## Проверочный запуск

`check-setup.mjs` проходит цепочку окружения — Node, точные версии, файл замка, установленное, сборка пакета, витрина — и печатает ожидание рядом с фактом, в конце итог числом. Запускать после переустановки окружения, на новой машине и когда надо отделить поломку окружения от поломки кода. `--no-build` пропускает сборку.

## Окружение

Node 24, npm 11. Версии зависимостей точные, без диапазонов.
